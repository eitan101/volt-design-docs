# Volt — Architecture, Design Decisions & Interactive Diagram Hub

Live mobile-friendly & offline-capable GitHub Pages site:
👉 **https://eitan101.github.io/volt-design-docs/**

## Highlights
- **7 System & Cloud Design Documents** — Specification, Domain Entities & ERD, Microservices & C4 Architecture, Sequence Flows & Verification, Dual-Region GCP Stack, and Local Stack & Simulators.
- **16 Touch-Zoomable Vector Diagrams** — Smooth 2-finger pinch-to-zoom, 1-finger pan with velocity inertia, double-tap focal zoom, `Readable` 1:1 text preset, and Fullscreen Studio (`100dvh`).
- **27 Searchable Architectural & GCP Decisions** — Filterable trade-off explorer comparing recommended choices vs. alternatives.
- **100% Offline & Installable PWA** — Open once while connected to automatically precache all documents, diagrams, and fonts for offline reading, or install to your iPhone/Android Home Screen (`Share -> Add to Home Screen` on iOS Safari, or `Install App` on Android Chrome).
